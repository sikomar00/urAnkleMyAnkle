[app] 폴더 설명
---------------------------------
용도: Plotly Dash로 만드는 통합 대시보드 앱입니다. 요건에서
요구하는 5개 화면(에너지 현황·예측·AI4I·데이터 조회·보고서
요약)을 이 폴더 안에서 구현합니다.

규칙:
- app.py는 앱 전체를 실행하는 진입점(entry point)입니다.
  화면 하나하나의 코드는 여기 두지 않고 app/pages/ 안의
  파일로 나눠서 넣습니다. 그래야 여러 명이 화면을 동시에
  각자 만들 수 있습니다.
- app/ 안의 코드는 outputs/*.csv와 models/*.joblib을
  "읽기만" 합니다. 여기서 모델을 새로 학습시키지 않습니다
  (학습은 src/, notebooks/ 담당).

하위 폴더:
- pages/  : 화면 5개, 화면당 파일 1개
- assets/ : Dash가 자동으로 불러오는 CSS 등 스타일 파일
