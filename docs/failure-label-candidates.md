# 설비 고장 정답 후보 비교

이 실험은 원본 `synthetic_industrial_machine_data.csv`의 부품별 `breakdown_flag`를 설비·날짜 단위로 모아, **어떤 상태를 설비 고장으로 볼지** 비교합니다. 미래 3일·7일 고장을 예측하는 실험은 아닙니다. 원본 CSV는 읽기만 합니다.

## 실행 파일과 고장 기준

| 실행 파일 | 주제 | 각각 별도로 만든 정답 |
| --- | --- | --- |
| `src/pd_BD_CO.py` | 고장 부품 수 | 하루에 고장 표시된 부품이 3·4·5·6·7개 이상 |
| `src/pd_BD_A.py` | A등급 부품 | A등급 1개 이상, A등급 2개 이상, A등급 1개 이상이면서 전체 2개 이상, A등급 2개 이상이거나 전체 4개 이상 |
| `src/pd_BD_COST.py` | 고장 부품 단가 합계 | 고장 표시 부품의 `unit_cost_inr` 합계가 1,000·2,500·5,000·10,000·20,000 INR 이상 |
| `src/pd_BD_START.py` | 고장 상태 시작 | 실제 전날 고장 부품 3개 미만에서 오늘 3개 이상, 또는 전날 중요도 10점 미만에서 오늘 10점 이상 |
| `src/pd_BD_CONSEC.py` | 이틀 연속 고장 상태 | 실제 전날과 오늘 모두 고장 부품 1개 이상, 또는 두 날 모두 2개 이상 |

중요도는 **고장 표시된** A등급 부품에 4점, B등급에 2점, C등급에 1점을 부여해 합산합니다. 원가 실험의 금액은 실제 수리비가 아니라 **고장 표시 부품의 단가 합계**입니다. 시작·연속일 실험은 전날 기록이 없거나 날짜가 하루라도 비면 그 행의 정답을 모르는 것으로 두고 학습·평가에서 제외합니다. 현재 원본에서는 설비별 첫날 10행이 제외되며 중간 날짜 공백은 없습니다.

## 공통 분석 방식

`src/pd_bd_common.py`가 다섯 파일의 데이터 집계, 정답 생성, 모델 학습, 표 출력과 CSV 저장을 담당합니다. 같은 설비·날짜에 반복된 부품 20행의 센서값을 설비 하루당 1행으로 줄입니다. 기존 중요도 점수 실험의 변수 구성을 그대로 사용해 **센서 8개만 사용한 실험**과 **센서·과거 변화 56개 및 설비 종류·공장 정보를 사용한 실험**을 구분합니다. `asset_tag`는 설비별 과거 계산과 결과 식별에만 쓰며 모델 입력에는 넣지 않습니다. 고장 표시, 정답과 그 정답을 직접 알려주는 집계값도 입력에서 제외합니다.

전체 날짜의 과거 70%를 Train, 다음 15%를 Validation, 최근 15%를 Test로 나눕니다. 결측 처리·표준화·범주 변환은 Train에서만 학습합니다. 각 정답마다 로지스틱 회귀와 랜덤 포레스트를 기본·`class_weight="balanced"` 방식으로 비교합니다. 고장 확률 **0.5 이상**을 고장으로 판정하며 Test 결과로 확률 기준을 조정하지 않습니다. 두 입력변수 구성과 두 알고리즘, 두 가중치 방식의 성적을 별도 행으로 남깁니다.

## 결과 파일을 읽는 순서

각 실험의 결과는 `outputs/pd_bd_co`, `pd_bd_a`, `pd_bd_cost`, `pd_bd_start`, `pd_bd_consec` 폴더에 각각 저장됩니다.

1. `label_rates.csv`: 기준별 전체·Train·Validation·Test 행 수, 실제 고장행 수와 비율, 전부 정상이라고 판정했을 때의 Accuracy입니다.
2. `overall_results.csv`: 기준·입력변수·알고리즘·가중치 조합별 Test Accuracy, Precision, Recall, F1, PR-AUC, TN·FP·FN·TP, 예측 고장 건수와 판정 기준입니다.
3. `asset_results.csv`: 같은 Test 결과를 `asset_tag`별로 나눈 표입니다. 실제 또는 예측 고장이 없어 Precision·Recall을 해석하기 어려우면 `note`에 이유가 표시됩니다.
4. `date_splits.csv`: 세 날짜 구간의 시작일·종료일·행 수입니다. 시작·연속일 실험에서는 전날을 알 수 없는 행을 제외하므로 `label_rates.csv`의 유효 행 수가 더 적습니다.

현재 원본에는 단가 합계 20,000 INR 이상인 고장일이 **0건**입니다. 이 기준은 정상·고장 두 종류의 학습 자료가 없어 모델을 만들지 않고 결과에 `학습 불가`로 표시합니다. 모델 점수가 높거나 고장률이 적당해 보인다는 이유만으로 해당 정답을 실제 현장의 설비 고장 기준으로 확정할 수는 없습니다.

## 실행

프로젝트 폴더에서 아래 명령을 하나씩 실행하면 표가 터미널에 나오고 CSV가 저장됩니다. 다른 원본을 쓰려면 각 명령 뒤에 `--data "C:\경로\파일.csv"`를 붙입니다.

```powershell
& .\.venv\Scripts\python.exe .\src\pd_BD_CO.py
& .\.venv\Scripts\python.exe .\src\pd_BD_A.py
& .\.venv\Scripts\python.exe .\src\pd_BD_COST.py
& .\.venv\Scripts\python.exe .\src\pd_BD_START.py
& .\.venv\Scripts\python.exe .\src\pd_BD_CONSEC.py
```

`tests/test_pd_bd_common.py`는 경계값, A등급 조합, 단가 합계, 설비의 첫날과 날짜 공백 처리를 확인합니다.
