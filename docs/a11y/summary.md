# 접근성 검사 결과 (axe-core 4.10.2)

`python -m scripts.a11y_check`로 생성한다. 화면 1~4는 데모 모드 1920×1080, 로그인은 1366×768.

| 페이지 | critical | serious | moderate | minor |
|---|---|---|---|---|
| screen1 | 0 | 0 | 0 | 0 |
| screen2 | 0 | 0 | 0 | 0 |
| screen3 | 0 | 0 | 0 | 0 |
| screen4 | 0 | 0 | 0 | 0 |
| login | 0 | 0 | 0 | 0 |

건수는 위반 노드 수다. 규칙별 상세는 같은 폴더의 `<페이지>.json`.

## 지시서 항목 실측 (화면 ①, 1920×1080)

| 항목 | 값 | 목표 |
|---|---|---|
| html lang | ko | ko |
| 드롭다운 placeholder 대비 | 5.60:1 | 4.5:1 이상 |
| 콤보박스 접근 이름 | 8개 입력에 이름 (드롭다운 4개) | 전부 |
| h1 개수 / 카드 제목 h2 | 1 / 예 | 1 / 예 |
| 세션 연장 버튼 | 39×24 | 24×24 이상 |
| 포커스 링(Tab 첫 요소 `div`) | 2px solid rgb(42, 120, 214), 오프셋 1px | 2px border-focus + 1px |
