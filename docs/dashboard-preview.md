# 설비 분석 대시보드

`huijae-work`에서 만든 독립 화면입니다. 기존 `app/app.py`에는 연결하지 않았습니다.

## 실행

프로젝트 의존성이 설치된 Python 환경에서 저장소 루트 기준으로 실행합니다.

```powershell
python -m src.dashboard
```

주소: http://127.0.0.1:8052

원본 `synthetic_industrial_machine_data.csv`는 `data/raw/` 또는 사용자 `Downloads/`에서 읽습니다. 다른 경로는 `MACHINE_DATA_PATH` 환경 변수로 지정할 수 있습니다. 원본 파일을 수정하거나 Git에 추가하지 않습니다.

## 현재 기능

- 전체 현황: 공장·설비·기간 필터, 고장 표시일 비교, 일별 평균 전력, 설비 목록. 목록의 행을 클릭하면 해당 설비의 상세 분석으로 이동합니다.
- 상세 지표: 기준일 센서값, 과거 중앙값 대비 변화, 기준일 고장 표시 부품 수.
- 상세 그래프: 센서 추이와 7개 관측일 이동평균, 동일 날짜 축의 고장 기록, 과거 분포와 기준일 위치.
- 부품 선택: 표의 행을 클릭하면 선택 부품의 고장 표시 그래프·기준일 상태·출고량·금액·출고 내역이 함께 갱신됩니다. 부품 선택 해제 버튼으로 설비 전체 고장 표시 부품 수를 다시 볼 수 있습니다. 설비를 바꾸면 부품 선택은 초기화됩니다.
- 기간: 직접 시작일·종료일을 입력하거나 종료일 기준 30일·90일·1년 버튼을 사용합니다.
- 표: 열 정렬과 검색, 페이지 이동. CSV는 검색·정렬 결과의 전체 페이지를 내보내며, 조회 조건과 한글 열 이름을 포함합니다.
- 추가 분석: 펼치기 영역에서 부하·전력 산점도와 선택 부품의 실제 출고일별 기록을 확인합니다.
- 모델 검증: 연결 상태와 평가 계획 표시.

## 해석 기준

- 센서는 기계·날짜별로 중복 제거합니다. 고장·출고는 부품별로 유지합니다.
- 고장 표시일은 사건 수가 아닙니다. 기준일은 조회 기간의 마지막 관측일입니다.
- 분포는 같은 설비의 기준일 이전 90개 관측이 기본이며, 30개 또는 전체 과거 관측으로 바꿀 수 있습니다. 기준일·미래 기록을 제외하며 조회 시작일 이전 자료도 포함할 수 있습니다.
- 분포 내 위치는 과거 값 중 기준일 값 이하인 관측의 비율입니다. 위험 점수나 고장 확률이 아닙니다.
- 중앙값 대비 변화는 센서의 원래 단위로 표시합니다. 양수라고 자동으로 위험으로 판정하지 않습니다.
- 이동평균은 해당 일까지 최근 7개 관측값입니다.
- 전력 단위는 kW이며 에너지 사용량 kWh로 합산하지 않습니다. 금액은 INR입니다.
- 합성 데이터의 기록이며 실제 현장 상태나 실시간 경보가 아닙니다.

## 아직 연결하지 않은 부분

- 향후 7일 고장 예측, 예측 위험 게이지, 영향 변수.
- 다음 관측일 전력 예측과 기준모델 비교.
- 실제 모델 성능, 혼동행렬, 확률 보정, 군집·이상 점수.
- 기존 팀 앱과의 통합.

위 항목에는 임의 점수나 가짜 성능을 넣지 않았습니다.

## 파일과 검증

- `src/dashboard.py`: 데이터 읽기·집계·화면·콜백.
- `src/dashboard_assets/dashboard.css`: 색상·배치·반응형 스타일.
- `tests/test_dashboard.py`: 원본 CSV가 있을 때 수행하는 6개 검증. 원본이 없으면 건너뜁니다.
- `docs/dashboard-handoff.md`: 작업 재개 안내.

기본 주소가 사용 중이면 `DASHBOARD_PORT` 환경 변수로 포트를 지정할 수 있습니다. 이전 버전 탭이 열려 있다면 새로고침해 주세요.
