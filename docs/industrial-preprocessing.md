# 산업기계 데이터 전처리

실행: `python -m src.prepare_machine_data`

다른 원본은 `--input 경로`, 결과 위치는 `--output-dir 경로`로 지정합니다. 기본 원본은 사용자 Downloads의 `synthetic_industrial_machine_data.csv`, 기본 결과는 `data/processed/industrial/`입니다.

## 결과 파일

| 파일 | 단위 | 행 수 | 용도 |
| --- | --- | ---: | --- |
| machine_df.csv | 기계·날짜 | 10,950 | 센서·전력 분석, 이상탐지 입력 준비 |
| part_df.csv | 기계·부품·날짜 | 219,000 | 부품 과거 이력과 미래 7일 고장 표시 정답 |
| feature_schema.json | 열 목록 | — | 모델 입력 허용 목록과 제외 열 |
| quality_report.json | 검사 결과 | — | 수치, 분할 경계, 원본 변경 여부 |

원본은 수정하지 않았습니다. 처리 전후 SHA-256이 같습니다. 가공 CSV는 저장소의 기존 규칙에 따라 Git에서 제외됩니다. 기존 `outputs/` 계약과 대시보드 데이터 경로는 변경하지 않았습니다.

## 계산 기준

- 예측 기준은 t일 종료입니다. 센서는 t일까지 알 수 있다고 가정합니다.
- 부품 고장·출고 과거 이력은 t-7~t-1, t-30~t-1만 사용합니다. 당일 정보는 제외합니다.
- `breakdown_days_prev_*d`는 고장 표시가 있었던 날짜 수이며 서로 다른 고장 사건 수가 아닙니다.
- `days_since_last_observed_breakdown`은 이전에 관측한 마지막 고장 표시 이후 경과일입니다. 과거 표시가 없으면 결측이며, 0으로 대체하지 않았습니다. `has_prior_observed_breakdown`으로 구분합니다.
- `target_breakdown_next_7d`는 현재 고장 표시가 0인 부품의 t+1~t+7 중 표시가 있으면 1, 없으면 0입니다. 현재 표시가 1이거나 미래 7일이 완전하지 않으면 결측입니다.
- 날짜 누락을 내부적으로 일 단위에 맞춰 확인하지만, 가상의 정상행을 결과에 추가하지 않습니다. 과거 기간의 하루라도 없으면 해당 이력 합계를 비워 둡니다.
- `machine_df`는 센서와 설비 정보, 센서 전일값·이전 7일 평균을 포함합니다. 임의의 설비 고장 정답을 넣지 않았습니다.
- `part_df`의 원래 열은 추적을 위해 보존합니다. 모델에는 반드시 `feature_schema.json`의 입력 허용 목록만 사용하세요. 원본 전체 열을 넣으면 안 됩니다.

## 학습용 행 선택

`eligible_for_model == True`인 행만 학습·평가 대상으로 사용하고 `split`으로 나눕니다. 이 표시는 현재 고장 표시 0, 완전한 미래 7일 정답, 완전한 과거 30일, 정답의 구간 경계 중첩 없음 조건을 모두 요구합니다.

| 구간 | 관측일 범위 | 학습·평가 가능 행 |
| --- | --- | ---: |
| train | 2022-01-03~2024-02-07 | 131,364 |
| validation | 2024-02-08~2024-07-20 | 28,327 |
| test | 2024-07-21~2025-01-01 | 28,514 |

공통 날짜 70%/15%/15% 기준입니다. 각 구간 마지막 7일은 미래 정답이 다음 구간을 침범하므로 모델 사용 대상에서 제외합니다. 해당 행 자체는 삭제하지 않습니다. 검증·평가 시점에 이미 알고 있는 이전 구간의 과거 기록은 이력 계산에 사용할 수 있습니다.

결측 보완, 범주 변환, 표준화는 학습 구간으로만 맞춰야 합니다. 이 전처리 단계에서는 모델을 학습하거나 전체 데이터 기준으로 결측을 채우지 않습니다. 후속 모델 학습은 `src/data_huijae.py`와 [모델 실행 문서](industrial-models.md)를 참고하세요. 최근 7일은 정답이 없어 학습 대상으로 쓰지 않을 뿐, 별도 추론 대상으로 사용할 수 있습니다.

## 실제 확인 결과

- 같은 기계·날짜의 센서 불일치: 0개 그룹.
- 부품별 고장 표시가 섞인 기계·날짜: 7,376개.
- 어느 부품에서든 표시가 있었던 기계·날짜: 7,376개. 이것을 실제 설비 정지일로 해석하지 않습니다.
- 설비 전체에 현재 표시가 없고 미래 7일을 모두 관찰할 수 있는 3,551개 중 향후 표시 비율: 100%.
- 현재 부품 표시가 0이고 미래 7일이 완전한 196,113개 중 향후 표시: 99,984개, 약 50.98%.
- `wo_type` 빈값: 176,207개. 작업 없음으로 임의 대체하지 않고 보존했습니다.

부품 단위의 양성·음성이 존재한다는 것만으로 예측력이 보장되지는 않습니다. 알려진 설비에 대한 시간순 평가이며 신규 설비 일반화는 별도의 검증이 필요합니다. 랜덤 분할 중복 수치는 이번 검사에서 재현하지 않았습니다.

검증: `pytest tests/test_prepare_machine_data.py -q` — 분석 단위, 당일 정보 제외, 미래 기록 부족, 날짜 누락, 분할 경계, 센서 불일치를 점검합니다.
