# 로그인 10분 세션 안내

## 동작

로그인에 성공하면 Flask 서버 세션에 `expires_at`을 현재 시각에서 10분 뒤로 저장합니다. 브라우저에 보이는 `MM:SS` 카운트다운은 안내용이며, 실제 접근 허용 여부는 서버가 매 요청마다 `expires_at`을 확인해 판단합니다.

우측 상단 **마이프로필**에는 로그인 아이디, 남은 시간, 검은색 새로고침 아이콘, 비밀번호 변경, 로그아웃이 표시됩니다. 새로고침 아이콘은 남은 시간에 10분을 더하지 않고 서버 만료 시각을 다시 현재 시각 + 10분으로 설정합니다. 따라서 화면 카운트다운은 언제나 최대 `10:00`입니다. 성공 시 `ACT_SESSION_EXTEND`를 `action_logs`에 저장합니다.

남은 시간이 정확히 10초가 되면 **로그인 시간 연장** 창이 나타납니다. 왼쪽 `예 (10초)` 버튼의 숫자는 실제 남은 시간에 맞춰 0초까지 감소하고, 오른쪽 `아니오` 버튼을 누르면 즉시 로그아웃합니다. 예를 누르면 10분으로 초기화됩니다. 아무 선택 없이 0초가 되면 자동으로 로그인 화면으로 이동합니다.

마이프로필의 로그아웃 버튼은 먼저 `로그아웃하시겠습니까?` 확인 창을 표시합니다. 비밀번호 변경이 성공하면 `비밀번호가 변경되었습니다. 다시 로그인해 주세요.` 안내 창의 확인 버튼을 누른 뒤 로그아웃됩니다. 로그인 실패는 폼 아래 문구 대신 중앙 안내 창으로 보이며, 확인 버튼 또는 팝업 바깥 영역을 클릭해 닫을 수 있습니다.

## 로그 이벤트

| 이벤트 코드 | 저장 시점 | 결과 |
| --- | --- | --- |
| `ACT_LOGIN` | 로그인 성공 | `SUCCESS` |
| `ACT_SESSION_EXTEND` | 새로고침 아이콘 또는 10초 확인 창에서 10분 초기화 | `SUCCESS` |
| `ACT_LOGOUT` | 로그아웃 확인, 연장 거절, 비밀번호 변경 완료 뒤 로그아웃 | `SUCCESS` |
| `ACT_SESSION_EXPIRED` | 10분이 지나 서버가 세션을 차단 | `TIMEOUT` |

만료된 세션은 서버에서 즉시 삭제하므로, 같은 세션으로 `ACT_SESSION_EXPIRED`가 반복 저장되지 않습니다. 만료된 브라우저의 Dash 데이터 요청은 `401`로 막히고 로그인 화면으로 이동합니다.

## 실행과 확인

```powershell
.\.venv\Scripts\python.exe src\wireframe_app.py
```

브라우저에서 `http://127.0.0.1:8052/`를 열어 로그인합니다. MySQL Workbench에서는 다음 조회로 최근 세션 로그를 확인합니다.

```sql
SELECT occurred_at, actor_id, event_code, result_status, block_reason
FROM testdb.action_logs
WHERE event_code IN ('ACT_LOGIN', 'ACT_SESSION_EXTEND', 'ACT_LOGOUT', 'ACT_SESSION_EXPIRED')
ORDER BY occurred_at DESC, log_id DESC;
```

## 테스트 범위

- 로그인 성공 시 서버 만료 시각이 10분 뒤로 설정되는지
- 새로고침 아이콘 또는 10초 팝업의 예를 누르면 만료 시각이 다시 10분 뒤로 바뀌는지
- 만료된 세션이 `/login`으로 이동하고 Dash 요청이 차단되는지
- 로그인 실패 안내, 로그아웃 확인, 비밀번호 변경 완료 안내가 올바르게 표시되는지
- 연장·만료·로그아웃 이벤트가 중복 없이 로그에 남는지
