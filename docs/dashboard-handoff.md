# 대시보드 작업 인계

## 작업 범위와 약속

- 현재 브랜치 `huijae-work`에서만 작업. main 전환·병합·푸시 금지.
- 사용자 호칭은 보스, 쉬운 한국어와 존댓말.
- CSV 실데이터로 분석형 대시보드 구현. 모델 학습은 이번 디자인 작업 범위 밖.
- 원본 CSV는 사용자 Downloads에서 읽고 수정하지 않음.
- 사용자 계정의 잔여 사용량은 확인할 수 없음. 자동 재개·백그라운드 사고를 약속하지 않음.

## 이번 개선 목표

1. 정보 우선순위와 글자 대비, 표의 숫자·단위 표현 개선.
2. 설비 목록 선택에서 상세 분석으로 이동.
3. 상세 KPI를 기준일 센서값·과거 대비 변화·부품 고장 기록으로 구성.
4. 센서 추이와 고장 표시를 같은 날짜 축에 정렬.
5. 부품을 선택하면 상태·최근 기록·출고 정보 갱신.
6. CSV 내보내기에 표 검색·정렬 결과와 조회 맥락 반영.
7. 브라우저에서 화면과 필터 동작 확인.

## 현재 상태

2026-09-22: 위 개선 목표 1~7 구현. 실제 CSV를 사용하는 분석 화면이며 모델 학습·추론은 하지 않았습니다.

- 남색 사이드바와 높은 대비, 일관된 숫자 형식, 상세 KPI 도입.
- 모든 화면 구성요소를 고정 배치하고 데이터만 갱신하도록 변경. 이전 동적 레이아웃의 콜백 연결 문제 해결.
- 설비 목록 행 클릭 → 설비·탭 전환을 브라우저에서 확인.
- 선택 부품 고장 표시를 센서 추이와 같은 날짜 축에 표시. 출고 상세 연동 확인.
- 부품 선택 해제와 설비 변경 시 초기화 기능 추가.
- 30일 빠른 조회, 90개 과거 관측 기준 분포 표시 확인.
- 표 검색·정렬 결과를 한글 열 이름과 조회 조건을 포함한 CSV로 내보냄.
- 탭 전환에서 그래프가 표와 겹치는 현상 발견 후 명시적 높이 지정, 브라우저 화면으로 수정 확인.
- `tests/test_dashboard.py` 6개 통과: 센서 중복 제거, 미래 관측 제외, 부품/센서 구분, CSV 검색 결과 및 조건 보존, 첫 관측일·빈 기간, 고유 화면 ID와 CSS 응답.

## 다음 작업자가 알아야 할 미완성 범위

- 고장 예측·전력 예측·위험 게이지·영향 변수·혼동행렬·확률 보정은 모델 결과가 없어 미연결.
- 기존 `app/app.py`와 아직 통합하지 않았음. 독립 실행형 유지.
- CSS에 작은 화면 대응 규칙이 있으나 이번 브라우저 시각 검토는 데스크톱 크기에서 수행.
- 필터·부품 선택은 메모리에만 유지되어 새로고침하면 기본 조건으로 돌아감.
- 기존 `venv`의 Python 경로 복구는 수행하지 않았음.
- 커밋·푸시·main 병합은 하지 않음.

## 실행 환경

- 기존 `venv/Scripts/python.exe`는 원래 Python 설치 경로가 없어 실행 불가.
- 이번 세션 검증은 Codex 내장 Python에 저장소 `venv/Lib/site-packages`를 추가해서 실행.
- 기본 로컬 주소는 http://127.0.0.1:8052 . 서버 생존 여부는 다시 확인 필요.
- 새로운 담당자는 `git diff`, `src/dashboard.py`, `docs/dashboard-preview.md`부터 확인.
