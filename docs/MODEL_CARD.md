# 모델 카드

대시보드 화면 ③에 나오는 네 과제의 모델 정보입니다.
- 수치는 모두 시험 구간이고, 괄호 안이 출처 파일입니다.
- 과제 ①~③은 `python -m src.model_comparison --task all`이 같은 분할로 기준선과 함께 다시 계산합니다.
- 대시보드는 저장된 결과를 읽기만 하고 학습하지 않습니다.

## 데이터

- **원본:** `data/raw/synthetic_industrial_machine_data.csv`
  - 219,000행 × 22열 합성 데이터
  - 2022-01-03~2025-01-01(1,095일) × 기계 10대 × 부품 20종
  - 출처는 [`DATA_SOURCES.md`](../DATA_SOURCES.md)에 있습니다.
- **집계 단위:** 기계·일(10,950행)과 기계·부품·일(219,000행)
- **센서:** 원본은 기계·일마다 같은 센서값이 부품 20행에 반복됩니다. 그래서 기계 단위 과제는 기계·일로 먼저 중복을 없앱니다.

| ② 부품 7일 내 고장 표시 | 기계·부품·일 | 향후 1~7일 안에 고장 표시가 1회 이상(오늘 고장 표시 행은 제외) | 당일 센서 + 전일까지 고장 이력 + 부품 정보, 17개 변수 | 7일 내 고장 표시 확률 |

## 기준선

- **기준 A:** 학습 구간 양성 비율을 모든 행에 같은 점수로 줍니다. AP가 양성 비율과 같아지는 하한선입니다.
- **기준 B:** 학습 구간의 그룹별 과거 양성 비율입니다(`src/baselines.py`). 학습에 없는 그룹은 기준 A 값을 씁니다.
  - ①은 기계별입니다.
  - ②·③은 기계×부품별입니다.

## 지표와 컷오프

- **주 지표는 AP(평균 정밀도)입니다.** 양성 비율이 과제마다 0.06~0.51로 달라서 AP와 함께 `ap_lift`(AP ÷ 양성 비율)를 봅니다.
- **보조 지표:** ROC-AUC, 컷오프에서의 정밀도·재현율·경보율, 상위 10% 정밀도(동점은 기댓값 처리), 정확도와 "항상 정상" 정확도
- **컷오프 정책**
  - ①·③은 검증 구간 F1 최대입니다.
  - ②는 원 실험이 검증 구간을 쓰지 않아 0.5로 고정입니다.
  - 화면 ③의 슬라이더는 저장된 예측 확률을 다시 이진화할 뿐이고 모델을 바꾸지 않습니다.
- **영향 변수:** 검증 구간 permutation importance(`scoring=average_precision`)입니다. 상관·인과가 아니라 "섞었을 때 AP가 떨어지는 정도"입니다.

## 한계

- **합성 데이터라 현장 성능을 뜻하지 않습니다.**
- **①·③·④는 같은 날의 센서로 같은 날의 상태를 판별합니다.** 고장을 미리 알려 주는 사전 예측이 아닙니다.
- **사전 예측 과제인 ②는 기준 B와 거의 같습니다.** 과거 고장 비율 이상의 정보를 센서에서 얻지 못했습니다.
- **잔여 수명이나 부품 교체 시점은 예측하지 않습니다.**
- **기계가 10대뿐입니다.** 기계별 기준 B와 종류별 결과는 표본이 작습니다.
