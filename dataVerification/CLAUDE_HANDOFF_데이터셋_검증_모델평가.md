### 분석 단위

- 한 행: `transaction_date + asset_tag + part_no`
- 원본 그레인 유지

### 타깃

`asset_tag + part_no`별 시간 정렬 후 다음과 같이 생성한다.


## 과제 C. 전력 회귀

### 목적

기계별 다음 관측일 `power_consumption_kw`를 예측한다.

### 분석 단위

기계×날짜 10,950행으로 중복 제거한다.

```python
machine_daily = df.drop_duplicates(
    ["transaction_date", "asset_tag"]
)
```

### 분할 행 수

- 학습: 7,280행
- 검증: 1,820행
- 평가: 1,850행

지연값 생성으로 초반 일부 행은 모델 입력에서 제외될 수 있으므로 Excel에 최종 유효 행 수도 별도 기록한다.

### 타깃

각 기계의 다음 관측일 전력:

```python
target_power_next = (
    machine_daily
    .groupby("asset_tag")["power_consumption_kw"]
    .shift(-1)
)
```

### 기준모델

1. 전일값 지속 모델
2. 지난주 같은 요일값, lag 7
3. 기계×평일/주말 평균

세 번째 기준모델의 평균은 반드시 학습 구간으로만 계산한다.

### 학습 모델

1. HistGradientBoosting Regressor
2. Prophet

Prophet 설정:

- 주간 계절성 사용
- 연간 계절성 끔
- 일간 계절성 끔
- 기계별 개별 모델 또는 기계 식별이 명확한 합리적 구조 사용
- 평가 지평은 다른 모델과 동일한 1일

현실적인 시간 제약이 있으면 매일 재학습 대신 7일 주기 재학습을 사용할 수 있으나, Excel의 `비고`에 반드시 기록한다.

### 회귀 입력 변수

- 전력 lag 1
- 전력 lag 2
- 전력 lag 7
- 전력 7일 이동평균
- 전력 14일 이동평균
- 전력 7일 표준편차
- 과거 시점의 부하율과 RPM
- 요일
- 주말 여부
- machine_type
- asset_tag

미래 날짜의 부하율, RPM, 센서값은 입력하면 안 된다.

### 평가 지표

- MAE
- RMSE
- R²
- MAPE
- Median Absolute Error
- 가장 강한 기준모델 대비 MAE 개선량
- 가장 강한 기준모델 대비 MAE 개선율
- 평가 건수

MAPE는 실제값이 0인 행이 존재하는지 먼저 확인한다. 0이 있으면 MAPE를 제외하거나 안전한 정의를 명시한다.

## 과제 D. K-Means 설비 상태 군집화

K-Means는 분류나 회귀가 아닌 비지도 군집 모델이다. 분류·회귀 성능표에 억지로 포함하지 말고 별도 시트에 기록한다.

### 데이터

- 기계×날짜 10,950행
- 센서 8종

### 처리

1. 학습 구간에서 기계 종류별 표준화 기준을 적합
2. 검증·평가 구간에는 학습 기준만 적용
3. k=2, 3, 4, 5, 6 비교
4. Silhouette Score로 후보 검토
5. 화면에는 최대 3개 군집 표현이 원칙이므로, 최종 k가 4 이상이면 이유를 설명하거나 k≤3 후보도 함께 비교
6. 이상점수는 배정 군집 중심까지의 거리

### 기록 지표

- k
- Silhouette Score
- Inertia
- 군집별 행 수
- 군집별 비율
- 군집별 센서 평균
- 군집별 고장 표시 관련 참고 통계
- 이상점수 평균, 표준편차, 상위 5% 기준값

군집에 정상·고장 라벨을 직접 붙이지 않는다. 센서 특성으로 설명한다.

# 4. 전처리와 누수 방지 필수 조건

1. 랜덤 분할 금지, 날짜 기준 분할 사용
2. 결측 보정기는 학습 구간에만 fit
3. OneHotEncoder는 학습 구간에만 fit
4. StandardScaler는 학습 구간에만 fit
5. 이동통계는 그룹별 시간 정렬 후 생성
6. 과거 고장률은 현재 행 또는 미래 행을 포함하지 않도록 `shift(1)` 적용
7. 회귀 지연값도 기계별 `shift` 후 생성
8. 7일 타깃은 t+1~t+7만 사용하고 당일은 포함하지 않음
9. 7일 과제는 현재 `breakdown_flag=0`인 행만 평가
10. 평가 세트는 모델·임계값 선택에 사용하지 않음
11. 확률 보정을 수행하면 보정기도 검증 또는 교차검증 절차에 맞게 학습하고 평가 데이터에 fit하지 않음
12. 모든 random_state는 42로 통일
