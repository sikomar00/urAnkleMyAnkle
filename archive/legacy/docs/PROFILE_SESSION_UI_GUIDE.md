# 마이프로필과 로그인 만료 화면 안내

## 마이프로필 구성

로그인 뒤 우측 상단 원형 프로필을 누르면 다음만 표시됩니다.

| 항목 | 동작 |
| --- | --- |
| 아이디 | 현재 로그인한 관리자 아이디를 표시합니다. |
| 남은 시간 | 서버가 발급한 10분 세션의 남은 시간을 `MM:SS`로 표시합니다. |
| `↻` 아이콘 | 클릭한 시점부터 세션을 다시 10분으로 초기화합니다. 시간을 누적하지 않습니다. |
| 비밀번호 변경 | 현재 비밀번호 확인 후 새 비밀번호를 Argon2id 해시로 교체합니다. |
| 로그아웃 | 확인 창에서 예를 눌렀을 때만 로그인 화면으로 이동합니다. |

## 팝업 흐름

```text
남은 시간 10초
  → 로그인 시간 연장 팝업
  → 예 (남은 초 표시)  → 10:00으로 초기화
  → 아니오            → 로그인 화면
  → 0초까지 무응답    → 자동 로그인 화면

로그아웃 클릭
  → 로그아웃 확인 팝업
  → 예                → 로그인 화면
  → 아니오            → 대시보드 유지

비밀번호 변경 성공
  → 완료 안내 팝업
  → 확인              → 로그인 화면
```

로그인 실패도 화면 하단 문구 대신 중앙 안내 팝업으로 표시됩니다. 확인 버튼이나 어두운 팝업 바깥 영역을 누르면 팝업만 닫히며 로그인 폼은 유지됩니다.

## DB 로그

| 상황 | `action_logs.event_code` | 비고 |
| --- | --- | --- |
| 로그인 성공 | `ACT_LOGIN` | `SUCCESS` |
| 새로고침 아이콘·연장 팝업의 예 | `ACT_SESSION_EXTEND` | 정확히 10분으로 재설정 |
| 로그아웃 확인의 예 | `ACT_LOGOUT` | `reason=manual` |
| 연장 팝업의 아니오 | `ACT_LOGOUT` | `reason=session_extend_declined` |
| 비밀번호 변경 완료 확인 | `ACT_LOGOUT` | `reason=password_changed` |
| 시간 만료 | `ACT_SESSION_EXPIRED` | `TIMEOUT` |

비밀번호 원문, AES 키, 개인정보 원문은 이 로그에 저장하지 않습니다.
