# 단일 관리자 로그인 안내

## 단일 로그인 계정

공개 회원가입과 관리자 등록 화면은 없습니다. 앱을 시작할 때 `.env`의 `DASHBOARD_ADMIN_ID`, `DASHBOARD_ADMIN_PASSWORD` 값으로 단일 관리자 계정을 한 번 자동 생성합니다. 현재 시연용 값은 `ankles` / `1234`이며, DB에는 비밀번호 원문이 아니라 Argon2id 해시만 저장됩니다. 앱 화면의 비밀번호 입력칸은 `●`로 가려집니다.

## 로그인 화면과 프로필

`python src/wireframe_app.py`로 실행하고 `http://127.0.0.1:8052/`를 열면 `/login`으로 이동합니다. 아이디와 비밀번호가 맞으면 기존 ①~⑤ 화면이 열립니다. 우측 상단의 원형 프로필을 누르면 **비밀번호 변경**과 **로그아웃**만 보입니다. 새 비밀번호는 4자 이상이어야 하고, 변경 후에는 다시 로그인해야 합니다. 회원가입·Firebase·Google 로그인·역할 등급은 없습니다.

## 보안과 DB

- `dashboard_admin_info.login_id`에 아이디, `password_hash`에 Argon2id 해시를 저장합니다. 이름·전화번호·이메일은 AES-256-GCM 암호문으로 저장합니다. 원문 비밀번호와 AES 키는 DB에 저장하지 않습니다.
- 로그인 성공 후 Flask의 서명된 세션 쿠키를 발급합니다. 서버가 매 요청에서 세션을 확인하며, 로그인하지 않은 `/_dash-layout`과 `/_dash-update-component` 요청은 401로 거부합니다. 화면을 숨기기만 하는 방식이 아닙니다.
- 로그인 세션 서명 키는 `.env`의 `DASHBOARD_SESSION_SECRET`입니다. 로컬 `.env`에는 이미 무작위 값이 설정되어 있으며 Git에서 제외됩니다. HTTPS로 배포할 경우 `DASHBOARD_COOKIE_SECURE=1`과 HTTPS 접속이 필요합니다.
- 화면의 작업자 ID 자기 기입란은 제거했습니다. `action_logs.actor_id`는 브라우저 값이 아니라 서버가 검증한 `login_id`를 사용합니다.
- 로그인 성공·실패, 로그아웃, 비밀번호 변경은 `action_logs`에 기록합니다. 비밀번호 원문·해시·암호화 키·개인정보는 로그에 남기지 않습니다. 예기치 않은 처리 오류는 `error_logs`에 기록합니다.
- 비밀번호 변경 시 현재 비밀번호를 확인하고 새 해시와 성공 로그를 한 트랜잭션으로 저장합니다. 변경 성공 후 현재 세션을 종료합니다.

## 확인 순서

1. 등록 계정이 1개인지 확인합니다.
2. 로그아웃 상태에서 `/` 접속이 `/login`으로 이동하고, Dash 데이터 주소가 401인지 확인합니다.
3. 잘못된 비밀번호가 거부되고, 올바른 계정으로 5개 탭이 열리는지 확인합니다.
4. 프로필의 비밀번호 변경 후 이전 비밀번호로 로그인할 수 없고 새 비밀번호로 로그인되는지 확인합니다.
5. 로그아웃 후 Dash 데이터 주소가 다시 401인지 확인합니다.

관련 코드: `src/dashboard_auth.py`, `src/wireframe_app.py`, `src/audit_service.py`, `src/security_service.py`. 자동 테스트: `tests/test_dashboard_auth.py`.
