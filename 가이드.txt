=====================================================================
프로젝트 전체 구조 가이드 (처음 레포를 열면 이 파일부터 읽기)
=====================================================================

이 문서는 "이 레포에 뭐가 어디 있고, 어떤 순서로 작업하면 되는지"를
한 번에 보여주기 위한 문서입니다. 각 폴더 안에는 "폴더설명.txt"가
따로 있으니, 특정 폴더로 들어갈 때는 그 폴더의 설명도 같이 읽으세요.

---------------------------------------------------------------------
1. 전체 지도 (데이터가 흘러가는 순서)
---------------------------------------------------------------------

  [data/raw]  원본 데이터 (건드리지 않음)
      ↓
  [notebooks]  또는 [src]  전처리 · 학습 · 분석
      ↓
  [outputs]  결과 파일 (csv)      [models]  학습된 모델 파일
      ↓                                ↓
              [app]  Dash 대시보드 (outputs와 models를 "읽기만" 함)
                     ↓
              [report]  최종 보고서 · 발표자료

핵심 규칙 한 줄:
  분석(학습)하는 사람과 화면(Dash) 만드는 사람은 outputs/ 안의
  정해진 파일(이름 · 컬럼)로만 소통합니다. 서로의 코드를 몰라도
  됩니다. 이 약속은 docs/data_contract.md 에 고정되어 있습니다.

---------------------------------------------------------------------
2. 폴더별 한 줄 요약
---------------------------------------------------------------------

  docs/       회의록 · 데이터 약속 · AI 사용 기록 · 트러블슈팅 기록
  data/       원본(raw) · 가공(processed) 데이터. Git에는 안 올라감
  notebooks/  탐색·실험용 (에너지 팀용 / AI4I 팀용 파일 분리됨)
  src/        여러 곳에서 재사용하는 파이썬 함수 (전처리, 검증 등)
  outputs/    분석 결과 csv. Dash가 읽는 "계약 파일들"
  models/     학습된 모델 파일(.joblib). Git에는 안 올라감
  app/        Dash 대시보드 앱 (화면 5개, 파일별로 분리)
  report/     최종 보고서 · 발표자료 원본
  tests/      간단한 자동 확인 코드 (재현성 증거용)

---------------------------------------------------------------------
3. 누가 어디를 주로 건드리는지 (역할 예시, 팀에서 재조정 가능)
---------------------------------------------------------------------

  에너지 담당    → notebooks/energy_eda.ipynb, src/energy_train.py,
                   outputs/energy_*.csv, app/pages/energy_status.py,
                   app/pages/forecast.py

  AI4I 담당      → notebooks/ai4i_model.ipynb, src/ai4i_train.py,
                   outputs/ai4i_*.csv, models/rf.joblib,
                   app/pages/ai4i.py

  통합/문서 담당 → app/app.py, app/pages/data_lookup.py,
                   app/pages/report_summary.py, docs/, report/,
                   README.md, requirements.txt

---------------------------------------------------------------------
4. 지금 상태 (레포를 받은 직후)
---------------------------------------------------------------------

  - outputs/ 안의 csv 파일들은 전부 "더미(가짜) 데이터"입니다.
    실제 모델 결과가 나오면 같은 이름 · 같은 컬럼 구조로 덮어쓰면
    됩니다. Dash 쪽 코드는 그대로 두고 파일만 바뀌면 됩니다.

  - notebooks/*.ipynb 는 제목 셀 하나만 있는 빈 노트북입니다.

  - src/, app/ 안의 .py 파일들은 함수 껍데기(뼈대)만 있고
    실제 내용은 TODO 주석으로 표시되어 있습니다.

  - docs/data_contract.md 에 outputs 파일들의 컬럼 구조가 이미
    정해져 있습니다. 컬럼을 바꿔야 하면, 반드시 이 파일부터
    먼저 수정하고 팀에 공유하세요 (여기가 안 맞으면 Dash가 깨짐).

---------------------------------------------------------------------
5. 작업 시작 전 체크리스트
---------------------------------------------------------------------

  [ ] python -m venv venv 로 가상환경 생성 후 활성화
  [ ] pip install -r requirements.txt
  [ ] pip install nbstripout && nbstripout --install
      (노트북 출력이 Git에 안 남게 해서 병합 충돌을 줄여줌)
  [ ] data/raw/ 에 원본 데이터 다운로드 (DATA_SOURCES.md에 기록)
  [ ] docs/data_contract.md 내용을 팀 전체가 한 번 읽고 합의
